# Stable Diffusion 1.5

Generate pictures through the original image page or image API. Realistic Vision 5.1 uses the separately supplied MSE VAE; DreamShaper 8 uses its baked VAE. Rust runs CLIP, UNet and VAE directly over native HIP kernels, keeping one component resident at a time.

Defaults follow the development-host configuration: 512×512, 25 DPM++ 2M steps, Karras schedule, CFG 5 for Realistic Vision and 7 for DreamShaper. The current port supports one image per request, dimensions from 64 through 512 in multiples of 64, and Euler or DPM++ 2M. Edits, LoRAs and transparent generation are not implemented. Initial prompt support is one CLIP context: at most 75 BPE tokens plus start/end markers. Longer prompt chunks, weighting, BREAK and selectable clip-skip are not yet ported; unsupported weighting syntax is rejected explicitly.

Model enable/disable, loading and unloading use the existing controls.
