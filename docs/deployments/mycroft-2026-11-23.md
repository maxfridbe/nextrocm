The integrated GPU reports a 512 MiB dedicated pool and 8 GiB GTT pool in
sysfs. An initial 3.75 GiB job cap was rejected before execution because it
exceeded the dedicated total used by the generic gate. The five isolated
hardware jobs were rerun with the stricter 512 MiB sampled DRM VRAM+GTT cap and
8 GiB available-host-memory reserve. Their sampled peaks were 149–206 MB.
No watchdog condition or numerical tolerance was relaxed.

The separate live-service monitor sampled the deployed backplane and workers,
with a conservative summed DRM peak of 511,115,264 bytes. This is sampled
VRAM+GTT accounting, not an allocator counter or a continuous guarantee. The
running backplane retains its telemetry HIP context; an empty KFD process list
is therefore not claimed after deployment.

The UI checks execute the real compiled application actions with Node upload
adapters and live HTTP services. They are not visual-browser automation. The
transcript check is a retained single-clip regression, not general ASR accuracy.
Other engines have library build/export/loading coverage; this deployment did
not rerun every registered model's complete numerical or performance suite.
The gfx1035 Inkling closure retains scalar prefill; the gfx803-specific batched
prefill option is not enabled by this deployment.

## Evidence and rollback

Mycroft retains the candidate, pinned jobs, raw samples, process mappings,
installed-file receipts and backup under:
`/var/home/maxfridbe/nextrocm-deploy-50993a5/`.
`receipts/final-deployment.json` binds the installed artifact hashes and verifies
that the registry and authentication token are unchanged. Raw configuration
backups may contain credentials and are not copied into the repository.

Rollback artifacts are in `backup/artifacts/`, with original presence recorded
in `backup/artifact-presence.json`. To roll back, first put the service in
maintenance and let active work finish, stop `nextrocm.service`, restore each
previously present artifact, remove only newly introduced artifacts listed as
absent in that manifest, and restart the same unit. Verify health before
clearing maintenance. Unrelated files and model weights should not be replaced.
